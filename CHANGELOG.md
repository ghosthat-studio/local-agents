# Changelog

## 1.0.0

First public release.

- Eight-step build guide for local agents, and a diagnosis path for agents that underperform.
- References: choosing engine, model and harness; memory; chunking and rolling history;
  structured output and reconciliation; review and evaluation; coding agents, including Claude
  Code on a local model.
- `scripts/check_local_stack.py`: read-only probe of local inference servers, context, GPU
  placement, memory and opencode config.
- Evals with synthetic fixtures.
- Installable as a Claude Code plugin, a plain skill folder, or a claude.ai / API zip.
